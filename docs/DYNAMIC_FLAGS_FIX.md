# DYNAMIC-FLAGS-001 — preserve host flags during dynamic query

User reports AE25::228: effect cannot change non-dynamic flag bits during PF_Cmd_QUERY_DYNAMIC_FLAGS. Baseline4e8f6af unconditionally copies global flags into both query output words. The existing callback test incorrectly expected that copy from zero-initialized outputs and therefore missed this host protocol violation.

Fix: retain the registered global/PiPL capability words unchanged; on dynamic query leave the host-provided words intact. This effect makes no parameter-dependent capability changes. Do not remove Smart/query/GUID registration or alter render/cache/color behavior. SDK25.6 AE_Effect.h documents the permitted per-flag selectors. A new16-combination callback regression includes zero, full and reduced flag sets; it fails on the old implementation and must pass after the fix.
