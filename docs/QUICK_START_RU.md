# Как начать

1. Добавьте FSTR-LUT на видео. Для обычной картинки оставьте настройки входа по умолчанию — даже если она выглядит плоской.
2. Начните с Natural. Поправьте экспозицию, затем контраст и насыщенность. Температуру и Tint меняйте, если нужен другой баланс цвета.
3. Выберите Look и подберите Look Amount.100 — полная сила; можно ввести больше100. Mix смешивает весь результат с исходником.
4. Smart Color Grading включает обработку с учётом найденных объектов. При повторном включении используются подходящие сохранённые маски.
5. Advanced нужен только для особого входа: известного камерного Log или линейного3D-рендера. Для3D выберите Linear RGB либо ACEScg согласно настройкам рендера. Если AE уже подготовил изображение, оставьте обычный вход.

Если профиль неизвестен, уточните его у автора файла. Плоский вид или32бита сами по себе не говорят, какой профиль выбрать.

Задача плагина — красиво покрасить доступную картинку. SDR не получает обратно детали, потерянные при записи. Сходство с профессионально покрашенным Log оценивается на реальном материале; прохождение технических тестов этого не подтверждает.
