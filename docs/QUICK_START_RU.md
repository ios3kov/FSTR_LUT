## Обновлённое управление цветом

**Auto Prepare SDR** — первый параметр; у нового эффекта включён. Для явно выбранных Log/3D-профилей SDR-подготовка пропускается. В старых проектах сохраняются прежние значения.

Свой LUT: **Look → Load LUT…**, затем выберите файл. Отдельной кнопки импорта и блока LUT file нет. Имя выбранного файла отображается в Look как «Custom: имя». Чтобы заменить файл, снова выберите последнюю строку «Load LUT…». Файл остаётся внешним; при переносе проекта перенесите LUT вместе с ним. Меню, импорт Cube и повторное открытие проекта проверены в AE. Русские имена в стандартном списке отображаются латиницей; путь к файлу сохраняется без изменений. Остальные границы проверки — в EXTERNAL_LUT.md.

# Как начать

1. Добавьте **FSTR Grading** из раздела **FSTR Effects** на видео. Для обычной картинки оставьте настройки входа по умолчанию — даже если она выглядит плоской.
2. **Auto Prepare SDR** подбирает основу яркости, контраста и насыщенности для плоского обычного видео. У нового эффекта опция включена. Включённый Detect Scene Changes позволяет подбирать подготовку отдельно для обнаруженных планов; настройки старых проектов сохраняются. Затем выбирайте Look. Для Log и 3D используйте известный профиль входа.
3. Начните с Natural. Поправьте экспозицию, затем контраст и насыщенность. Температуру и Tint меняйте, если нужен другой баланс цвета. В новых эффектах Contrast использует более мягкую общую кривую яркости; в Advanced это переключатель Natural Contrast. Старые проекты сохраняют прежний вариант.
4. Выберите Look и подберите Look Amount. 100 — полная сила; можно ввести больше 100. Mix смешивает весь результат с исходником.
5. Smart Color Grading включает обработку с учётом найденных объектов. При повторном включении используются подходящие сохранённые маски.
6. Advanced нужен только для особого входа: известного камерного Log или линейного 3D-рендера. Для 3D выберите Linear RGB либо ACEScg согласно настройкам рендера. Если AE уже подготовил изображение, оставьте обычный вход.

Если профиль неизвестен, уточните его у автора файла. Плоский вид или 32 бита сами по себе не говорят, какой профиль выбрать.

Задача плагина — красиво покрасить доступную картинку. SDR не получает обратно детали, потерянные при записи. Сходство с профессионально покрашенным Log оценивается на реальном материале; прохождение технических тестов этого не подтверждает.

## Первый Smart-рендер

После добавления эффекта модель готовится в фоне. Строка **Smart: loading model…** означает загрузку; первый Smart-рендер может подождать её завершения. **Smart: ready** означает готовность. Обычный режим доступен без анализа кадра.

Если показано **Smart: unavailable**, проверьте установку плагина и его моделей. Запрошенный Smart-рендер завершится ошибкой; для обычной тонировки выключите Smart.

Выключение Smart сохраняет подходящие маски. При включении они используются снова; смена Look или Look Amount меняет цвет без повторного анализа. Изменение входного изображения или настроек анализа требует новых масок.
