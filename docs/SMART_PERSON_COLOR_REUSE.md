## Implementation

Private SkinToneLook::people_from_ordinary optionally writes the already float-rounded full correction to a fixed16-entry array supplied by its owning SceneLook. stable_from_ordinary uses these exact results after normal person computation and stable validation, instead of evaluating skin again. All weights and subtraction remain in the original order. Array is pixel-local256bytes, never retained; limit and reference validation precede writes; every read has a completed matching write. Empty stable path requests no writes. No new public API, allocation, persistent cache, native analysis-policy invalidation or UI parameter/state changes.
